# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately before opening a public issue or pull request. If GitHub Private Vulnerability Reporting is enabled for this repository, use the **Report a vulnerability** option on its GitHub Security page. If that option is unavailable, ask the repository maintainer through a private GitHub contact channel for a secure reporting method; avoid posting exploit details publicly.

Include the affected component, steps to reproduce, potential impact, and any relevant evidence. Do not include credentials or other people's private data. No response time or support period is promised here.

The project has no published supported-version policy. Consult the [README](README.md#scope-and-limitations) for deployment limitations.
